# 동화책 아카이브 (초기 구현본)

독립형 웹앱입니다. 기존 그림책 아카이브의 Supabase나 설정을 변경하지 않습니다.

## 현재 구현 범위
- 반응형 도서 목록 화면
- 제목/작가 검색, 학년/작가/출판사/주제어 필터, 페이지 나눔
- 로그인/회원가입 API, 서버 세션 쿠키
- 도서 등록/수정/삭제 권한 확인
- 직접 입력 주제어 저장 및 주제어 탐색
- YES24 검색 함수 이식(실제 API 연결은 환경 변수 설정 후 검증 필요)
- Neon용 초기 스키마 SQL

## 설정 순서
1. GitHub에서 새 저장소를 만듭니다.
2. Neon에서 새 프로젝트/데이터베이스를 만들고 SQL Editor에서 `sql/schema.sql` 전체를 실행합니다.
3. 이 프로젝트 폴더를 새 GitHub 저장소에 올립니다.
4. Netlify에서 새 사이트로 연결하고 배포합니다.
5. Netlify 환경 변수에 아래 값을 등록합니다.
   - `DATABASE_URL`: Neon의 pooled connection string 권장
   - `YES24_book_API_KEY`: 기존 YES24 API 키
   - `SIGNUP_MEMBER_CODE`: `동화사랑`
   - `SIGNUP_ADMIN_CODE`: `동화책사랑` (Netlify 환경 변수에만 입력, 저장소에 기록하지 않기)
6. `SESSION_SECRET`: 충분히 긴 무작위 값으로 생성해 등록합니다. 현재 초기 버전은 세션 토큰 자체를 무작위로 생성해 DB에 해시 저장하므로 이 변수는 후속 강화 작업에서 활용할 예정입니다.
7. 배포 후 `/` 접속, 회원가입, 도서 등록, 로그아웃 후 공개 열람, YES24 검색을 순서대로 점검합니다.

## 로컬 개발
- Node.js 20 이상
- `npm install`
- `npm run check`
- Netlify CLI로 함수와 정적 사이트를 함께 실행하는 것을 권장합니다.
- `.env.example`을 참고하되 실제 비밀값을 저장소에 올리지 마세요.

## 중요 사항 / 미완료 검증
- 이 실행 환경에는 실제 Neon 연결 문자열과 YES24 API 키가 없어 외부 서비스 통합 테스트는 수행할 수 없습니다.
- YES24 API의 현재 인증/응답 규격은 배포 환경에서 확인해야 합니다.
- 초기 회원가입 코드는 공유형 코드입니다. 특히 관리자 가입 코드는 유출되면 관리자 가입이 가능하므로 제한된 환경 변수로 관리하고, 운영 전 관리자 초대 방식/요청 제한을 강화하는 것을 권장합니다.
- 초기 버전은 표지 URL만 저장합니다. 파일 업로드 기능은 포함하지 않았습니다.
- 중복 제목+작가의 DB 제약 조건이 동시 등록 중복을 방지합니다. 중복 오류는 사용자에게 안내됩니다.
